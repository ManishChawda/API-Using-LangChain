# API-Using-LangChain

Examples demonstrating integration of LangChain with external APIs and Sophos APIs.

## Features

* LangChain Basics
* LLM Integration
* Groq Integration
* API Calls
* Tool Calling
* Security Automation Use Cases

## Requirements

* Python 3.11+
* LangChain
* LangChain-Groq
* Requests

## Installation

```bash
pip install -r requirements.txt
```

## Environment Variables

Create a `.env` file:

```env
GROQ_API_KEY=your_api_key
CLIENT_ID=your_client_id
CLIENT_SECRET=your_client_secret
```

## Run

```bash
python langchain_fastapi_sophosapi_1.py
```

## Learning Objectives

* LangChain Fundamentals
* LLM Integration
* API Automation
* Security Operations Use Cases
